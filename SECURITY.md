# Security policy

Veriplane is alpha software and does not yet have a supported production release.

Please do not disclose a suspected vulnerability in a public issue. Email the repository owner through the address listed on their GitHub profile with the subject `VERIPLANE SECURITY`. Include affected revision, reproduction steps, impact, and any suggested mitigation. Expect an acknowledgement target of five business days; this is a target, not an SLA.

Only the latest commit on `main` is currently in scope. Provider vulnerabilities, social engineering, and attacks requiring a deliberately exposed unauthenticated local server are out of scope, but hardening suggestions are welcome.
